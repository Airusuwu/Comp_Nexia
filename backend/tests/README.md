# Pruebas pendientes

Esta carpeta reserva las pruebas del backend y del lenguaje. Todavía no hay
una suite automatizada ni un comando `npm test`; no interpretar su ausencia
como una validación satisfactoria del compilador.

Al implementar cada componente, cubrir casos válidos e inválidos de tokens,
AST, tipos, símbolos y diagnósticos. Las reglas y casos del PDF se incorporarán
solo después de su revisión en el punto 6, sin incluir el PDF en Git.

La integración deberá comprobar editor, API, entrada/salida real, detención,
límites de ejecución, conservación del código ante errores y accesibilidad.
Los casos del lenguaje no deben requerir arrancar el servidor HTTP.
